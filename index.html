Create Preset

Provides the ability to quickly create preset projects.

Get Started
  • 🧰

    Practicality

    Supports everything from starter templates to complex projects.

  • ⚡️

    Efficient

    Reduces repetitive configuration processes every time a new project is created.

  • 🤹

    Interactive

    Simple command-line interactive operation.

  • 🛠

    Multi-Tech Stacks

    Provide commonly used multiple technology stack project support.

  • 🎛️

    Project customization

    Use the same template to create projects with different configurations.

  • 🔑

    Private Configuration

    Manage private project sources in a local config.

Try it out

Run one of the following commands and follow the prompts.

pnpm create preset
