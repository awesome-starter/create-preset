# Social preview font

`NotoSansSC-Regular.woff` is the complete Noto Sans SC Regular font, converted
from OpenType to WOFF without removing glyphs. It supports English and Chinese
social previews without requests to a remote font service during builds.

Source: [Noto CJK](https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf).
