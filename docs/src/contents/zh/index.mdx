# Create Preset

Create Preset 支持官方脚手架、私有模板和 JSON 配置。

Preset 是用于创建项目的模板或配置，来源可以是 Git 仓库或 `preset.json` 文件。

## 选择项目来源

- **官方脚手架**：调用 Vue、Nuxt、Vite、Next.js 等官方 CLI。
- **私有 Preset**：把常用仓库加入本地配置。同一技术栈下，私有选项会排在官方选项前面。
- **Preset 配置**：用 `preset.json` 指定模板目录和文件修改步骤。

## 开始使用

安装和使用方法见[快速开始](/zh/guide/getting-started)，支持的框架见[官方脚手架](/zh/guide/official-generators)。

团队模板可以添加为[私有 Preset](/zh/guide/private-presets)。模板放在 monorepo 中，或创建时需要修改文件，可以使用 [Preset 配置](/zh/guide/preset-configs)。

从旧版本升级时，请先查看[迁移到 1.0](/zh/guide/migration)，确认脚本中是否使用了已移除的选项。
