## 创建这个项目

安装 Node.js、Git 和 pnpm 后运行：

```bash
pnpm create preset init my-docs --from https://raw.githubusercontent.com/chengpeiquan/blackwork/main/presets/docs-starter.json
cd my-docs
pnpm install
pnpm dev
```

打开 `http://localhost:3300`。运行 `pnpm build` 和 `pnpm start`，
即可在 `http://localhost:4300` 预览静态站点和搜索索引。
上方截图来自实际生成的模板；文档站指南介绍了站点用途、配置方式和部署步骤。

如果你维护了可供他人使用的模板，欢迎[提交案例建议](https://github.com/preset-cli/create-preset/issues/new?template=showcase.yml)，
