# Create Preset

Create Preset supports official generators, private templates, and JSON configs.

A preset is a template or config for creating projects. Its source can be a Git repository or a `preset.json` file.

## Choose a project source

- **Official generators**: run the official Vue, Nuxt, Vite, Next.js, or other supported CLI.
- **Private presets**: add frequently used repositories to a local config. Private options appear before official generators within each stack.
- **Preset configs**: specify the template directory and file changes in `preset.json`.

## Get started

See [Getting Started](/guide/getting-started) for installation and usage, and [Official generators](/guide/official-generators) for supported frameworks.

Add an existing team template as a [private preset](/guide/private-presets). For templates in a monorepo, or those that need file changes during setup, use a [preset config](/guide/preset-configs).

When upgrading from an earlier version, check [Migration to 1.0](/guide/migration) for removed options that may affect existing scripts.
