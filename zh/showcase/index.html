Blackwork Docs Starter

支持 Markdown 和 MDX、中英文内容、主题切换与静态搜索的文档站模板。由 Blackwork 维护，通过公开 Preset 创建。

创建这个项目

安装 Node.js、Git 和 pnpm 后运行：

Bash
pnpm create preset init my-docs --from https://raw.githubusercontent.com/chengpeiquan/blackwork/main/presets/docs-starter.json
cd my-docs
pnpm install
pnpm dev

打开 http://localhost:3300。运行 pnpm build 和 pnpm start， 即可在 http://localhost:4300 预览静态站点和搜索索引。 上方截图来自实际生成的模板；文档站指南介绍了站点用途、配置方式和部署步骤。

如果你维护了可供他人使用的模板，欢迎提交案例建议， 附上公开 Preset 地址、项目链接、截图和已验证的创建命令。 了解如何编写 Preset 配置。
