Create Preset

提供快速创建预设项目模板的能力。

快速开始
  • 🧰

    实用性

    从入门模板到复杂项目均可支持。

  • ⚡️

    高效的

    减少每次创建新项目时的重复配置过程。

  • 🤹

    交互式

    简单的命令行交互式操作。

  • 🛠

    多技术栈

    提供常用的多种技术栈项目支持。

  • 🎛️

    项目定制

    同一模板可用于创建不同配置的项目。

  • 🔑

    私有配置

    通过本地配置管理私有项目源。

简单体验

运行以下命令，并按照提示进行操作。

pnpm create preset

功能预览

选择 Vue 后可使用 Vue 官方 Starter 或 Nuxt。
