Blackwork Docs Starter

A documentation starter with Markdown and MDX, bilingual content, theme controls, and static search. Maintained by Blackwork and created through a public preset.

Create this project

With Node.js, Git, and pnpm installed, run:

Bash
pnpm create preset init my-docs --from https://raw.githubusercontent.com/chengpeiquan/blackwork/main/presets/docs-starter.json
cd my-docs
pnpm install
pnpm dev

Open http://localhost:3300. Run pnpm build and pnpm start to preview the static export and its search index at http://localhost:4300. The screenshot above shows the generated starter. The Docs Starter guide explains what the documentation site is for and how to configure and deploy it.
